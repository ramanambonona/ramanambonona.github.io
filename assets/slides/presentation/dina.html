Introduction et Problématique

L’analyse économique du droit et l’approche institutionnelle offrent un cadre pour évaluer l’efficacité des institutions juridiques.

Question centrale : Dans quelle mesure le Dina peut-il être un mécanisme institutionnel efficient ?
Hypothèse clé : Le Dina minimise les coûts de transaction relativement au système formel, sous conditions.

En l’absence de coûts de transaction, l’allocation initiale des droits n’affecte pas l’efficacité de l’allocation finale.

Coase (1960), The Problem of Social Cost

Essai de définition

Cadre Théorique : Définitions

Définition 1 (Institution informelle)

Ensemble de règles \(\,R=\{r_1,\dots,r_n\}\,\) et mécanismes d’application \(\,M=\{m_1,\dots,m_k\}\,\) émergeant de l’interaction sociale.

Théorème de Coase

Soit \(E\) l’ensemble des agents et \(\Omega\) les allocations. Si \(CT=0\), l’allocation d’équilibre \(\omega^{\star}\in\Omega\) est Pareto-efficiente.

Modèle économique du Dina

Cadre analytique

Communauté de \(N\) agents homogènes, \(i\in\{1,\dots,N\}\).

\[ U_i(s_i,s_{-i},\theta) = u_i(s_i,s_{-i}) - C_i(\theta) + \sum_{j\neq i} E_{ij}(s_j,\theta). \]
  • \(u_i(s_i,s_{-i})\) : fonction d’utilité (ou gain/payoff) de l’agent \(i\).
  • \(s_i\) : stratégie / action de l’agent \(i\) (adhérer au régime Formel/Dina)
  • \(s_{-i}\) : profil des stratégies des autres agents (tous sauf \(i\))
  • \(\theta\in\{\theta_F,\theta_D\}\) : régime (Formel \(F\)/Dina \(D\)).
  • \(C_i(\theta)\) : coûts institutionnels ; \(E_{ij}\) : externalités

Fonction de coût institutionnel

\[ C_i(\theta) = C_i^{acc}(\theta) + C_i^{inf}(\theta) + C_i^{enf}(\theta) + C_i^{coord}(\theta). \]
\(C_i^{acc}\) : accès au système.
\(C_i^{inf}\) : information.
\(C_i^{enf}\) : application.
\(C_i^{coord}\) : coordination.

Proposition 1 : Avantage comparatif

Énoncé

Le Dina domine le système formel ssi

\[ \sum_{i=1}^{N}\!\big[C_i(\theta_F)-C_i(\theta_D)\big] \;>\; \sum_{i=1}^{N}\!\big[u_i(\theta_F)-u_i(\theta_D)\big]. \]

Preuve — Proposition 1

  1. Bien-être agrégé. \(W(\theta)=\sum_i [u_i(\theta)-C_i(\theta)] + \sum_{i\ne j}E_{ij}(\theta)\).
  2. Différence. \(\Delta W=W(\theta_D)-W(\theta_F)=\sum_i\Delta u_i - \sum_i\Delta C_i + \sum_{i\ne j}\Delta E_{ij}\).
  3. Hypothèse de comparabilité. Si \(\sum_{i\ne j}\Delta E_{ij}\approx 0\), alors \(\Delta W\approx \sum_i\Delta u_i - \sum_i\Delta C_i\).
  4. Conclusion. \(\Delta W>0 \iff \sum_i[C_i(\theta_F)-C_i(\theta_D)]>\sum_i[u_i(\theta_F)-u_i(\theta_D)]\). □

Théorème : Équilibre évolutionnairement stable (EVS)

Notations. \(U_X^{YZ}\) ; gain du joueur qui choisit \(X\in\{D,F\}\) dans une population résidente \(Y\) (avec opposants \(Z\), cadre symétrique). En particulier,

  • \(U_D^{DD}\) : payoff d’un joueur D en population D ;
  • \(U_F^{FD}\) : payoff d’un mutant F en population D ;
  • \(U_D^{DF}\) : payoff d’un mutant D en population F ;
  • \(U_F^{FF}\) : payoff d’un joueur F en population F.

Énoncé. Le régime Dina est EVS si :

  1. \(\;U_D^{DD}\ge U_F^{FD}\;\) (stabilité : en population D, F ne fait pas mieux) ;
  2. \(\;U_D^{DD}> U_F^{FD}\;\) ou \(\;U_D^{DF}>U_F^{FF}\;\) (résistance : stricte au bord, ou avantage de D lorsqu’on s’éloigne vers une population F).

Preuve

  1. Réplication. \( \dot{\pi}=\pi(1-\pi)\,[EU_D(\pi)-EU_F(\pi)]\).
  2. Au bord. \(EU_D(1)=U_D^{DD}\), \(EU_F(1)=U_F^{FD}\Rightarrow \dot{\pi}\!\!\big|_{\pi\to 1^-}\le 0 \iff U_D^{DD}\ge U_F^{FD}\).
  3. Mutation. Pour \(\pi=1-\varepsilon\) : \(EU_D(1-\varepsilon)-EU_F(1-\varepsilon)\approx U_D^{DD}-(1-\varepsilon)U_F^{FD}-\varepsilon U_F^{FF}\).
  4. Résistance. La (2) assure \(\dot{\pi}<0\) pour toute petite \(\varepsilon>0\). □

Analyse de sensibilité

Résultat

L’efficacité relative du Dina croît avec la taille jusqu’à \(N^{\star}\), puis décroît :

\[ \frac{\partial \Delta W}{\partial N}>0 \text{ si } N < N^{\star},\quad \]
\[ \frac{\partial \Delta W}{\partial N} < 0 \text{ si } N > N^{\star}. \]

Intuition : coordination plus facile dans petites communautés ; économies d’échelle du formel au-delà de \(N^{\star}\).

Implications normatives

Régulation optimale

\[ W^{opt}=\max_{\alpha,\beta}\; \alpha W_F+(1-\alpha)W_D-\beta\,C_{coord}. \]

Corollaire (pluralisme optimal)

\[ \frac{\partial W_F}{\partial \alpha}-\frac{\partial W_D}{\partial \alpha} \;=\; \frac{\partial C_{coord}}{\partial \beta}\cdot\frac{\partial \beta}{\partial \alpha}. \]

Équilibre entre systèmes formel/informel via la minimisation des coûts de coordination.

Recommandations politiques

  • Coordination : interfaces opérationnelles entre systèmes.
  • Subsidiarité : déléguer lorsque le Dina est efficient.
  • Capacitation : former les médiateurs communautaires.
  • Mesure : indicateurs d’efficacité : coûts/délais/conformité/satisfaction.

Le pluralisme juridique améliore l’efficacité allocative s’il est coordonné, évaluable et réactif aux hétérogénéités locales.

\[ \mu_i \sim F(\mu). \]

Apprentissage

\[ \dot{\pi}(t)=\pi(t)\,[1-\pi(t)]\,\Delta U(\pi(t)), \qquad \Delta U(\pi)=EU_D(\pi)-EU_F(\pi). \]

Conclusion

  • Le Dina présente un avantage comparatif significatif en termes de coûts de transaction, particulièrement dans les communautés de petite taille, sous réserve que les normes communautaires internalisent efficacement les externalités.
  • Reconnaissance institutionnelle : Légitimer le rôle des institutions informelles efficaces.
  • Politique : coordonner les systèmes et viser un pluralisme optimal.
