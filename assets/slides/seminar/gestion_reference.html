  • 1 Télécharger Mendeley Desktop :
    https://www.mendeley.com/download-desktop-new/
  • 2 Créer et ouvrir un compte Mendeley
  • 3 Relier Mendeley à Ms Word : dans Mendeley, sélectionner Tools → Install Ms Word Plugin

    (a) Saisie manuelle des références  |  (b) Importation via les plateformes numériques
Style de citation
Choisir le bon style de citation

Le style dépend de la revue / journal (articles à soumettre) ou de la norme institutionnelle.

  • Vancouver : numérotation entre parenthèses — ex. (1)
  • IEEE : numérotation entre crochets — ex. [1]
  • APA : auteur-année — ex. (Auteur, 2026)
Insertion de citation dans Ms Word
Workflow dans Ms Word avec Mendeley
① Insérer une citation
  • Placer le curseur à l'endroit voulu
  • Références → Insert Citations
② Choisir un style
  • Références → Mendeley → Styles
③ Insérer la bibliographie
  • Placer le curseur à la fin du document
  • Références → Insert Bibliography
④ Mettre à jour
  • Références → Refresh

Citation dans Ms Word
Insérer une citation dans Word
  • 1 Dans le document Word, placer le curseur à l'endroit d'insertion de la référence
  • 2 Aller dans l'onglet Références → Insert Citation
  • 3 Taper les mots-clés pour trouver la référence — ex. Deffains_Rouillon_2018
  • 4 Cliquer sur OK — ou sur Go to Mendeley pour sélectionner directement

Citation dans Ms Word — Bilan
Avantage clé de Mendeley

Une fois les références saisies et gérées automatiquement via Mendeley, il suffit de choisir le style de citation approprié et toutes les références (ainsi que la bibliographie) seront converties automatiquement selon la norme demandée — par exemple : normes des revues nationales ou internationales où vous souhaitez soumettre votre article.
