Module I — Micro Solver : Microéconomie

4 grandes familles de problèmes microéconomiques — du cours au niveau doctoral

1. Théorie du Consommateur

  • Maximisation d'utilité (Marshallienne) — demande ordinaire
  • Minimisation de la dépense (Hicksienne) — demande compensée
  • Fonctions : Cobb-Douglas CES CARA Quasi-linéaire Leontief

2. Théorie du Producteur

  • Minimisation du coût sous contrainte de production
  • Fonctions : Cobb-Douglas CES Leontief

3. Équilibre de Marché

Offre, demande, prix et quantités d'équilibre — concurrence parfaite, monopole, oligopole.

4. Théorie des Jeux

Équilibres de Nash, jeux statiques/dynamiques, information complète ou incomplète.

Exemple concret

U(x₁,x₂) = x₁αx₂1−α
s.c.  p₁x₁ + p₂x₂ = R

→ L'IA résout le pbm d'optimisation, les demandes Marshallienne et Hicksienne, les fonctions d'utilité indirecte et de dépense.

Macro Solver — Spécifier un Modèle Pas à Pas

Exemple : Modèle RBC standard avec choc technologique

Ce que vous saisissez

  • Fonction d'utilité — ex : U(Cₜ,Lₜ) = log(Cₜ) + θlog(1−Lₜ)
  • Fonction de production — ex : Yₜ = Aₜ Kₜ^α Lₜ^(1−α)
  • Processus de choc — ex : log(Aₜ) = ρ log(Aₜ₋₁) + εₜ
  • Contraintes — accumulation du capital, ressources

Ce que l'IA génère

  • Conditions du premier ordre (Lagrangien)
  • Équation d'Euler — consommation intertemporelle
  • État stationnaire — valeurs d'équilibre de long terme
  • Log-linéarisation autour de l'état stationnaire
  • Interprétation économique de chaque résultat

Modèle New Keynesian

Courbe IS · Courbe de Phillips · Règle de Taylor — dérivées analytiquement avec rigidités de prix Calvo.

Tutoriels Micro — Exemple Pas à Pas

Accessibles via l'onglet Tutorials du site — avec exemples complets et instructions détaillées

Cas 1 : Théorie du Consommateur

  1. Sélectionner "Consumer Theory" dans le menu
  2. Choisir le type de fonction : Cobb-Douglas
  3. Saisir : U(x₁,x₂) = x₁^α x₂^(1-α)
  4. Saisir la contrainte : p₁x₁ + p₂x₂ = R
  5. Activer "Show Detailed Steps" + "Use LaTeX"
  6. Cliquer "Solve" → solution complète générée

Cas 2 : Théorie du Producteur

  1. Sélectionner "Producer Theory"
  2. Choisir Cobb-Douglas comme type de production
  3. Saisir : Q = K^α L^(1-α)
  4. Contrainte de coût : wL + rK = C
  5. → L'IA dérive les demandes conditionnelles de facteurs, la fonction de coût et les conditions TMSKT

Ce que l'IA dérive automatiquement

Conditions d'optimum · Demandes Marshallienne & Hicksienne · Utilité indirecte · Dépense minimale · Identités de Slutsky · Dualité

Tutoriels Macro — Modèles Avancés

Cas 1 : Modèle RBC Complet

  1. Sélectionner "Real Business Cycle (RBC)"
  2. Utilité : U(Cₜ,Lₜ) = log(Cₜ) + θ log(1−Lₜ)
  3. Production : Yₜ = Aₜ Kₜ^α Lₜ^(1−α)
  4. Choc : log(Aₜ) = ρ log(Aₜ₋₁) + εₜ
  5. → Équation d'Euler, état stationnaire, log-linéarisation

Cas 2 : Modèle DSGE

Les DSGE intègrent plusieurs agents, des rigidités nominales et des chocs multiples.

  • Spécifier les préférences des ménages
  • Spécifier la production des firmes
  • Règle de politique monétaire (Taylor)
  • Processus de chocs (monétaire, préférence)
  • Fournir les valeurs de calibration dans la description
