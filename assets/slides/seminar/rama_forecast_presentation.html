C'est quoi RAMA-FORECAST ?

Une application web gratuite qui permet de prévoir des séries temporelles sans écrire une seule ligne de code.

Pour qui ?

  • Doctorants en économie, finance, sciences sociales
  • Chercheurs ayant des données chronologiques
  • Analystes souhaitant comparer plusieurs modèles
  • Toute personne avec un fichier Excel ou CSV

Ce que l'outil fait

  • Importe & nettoie automatiquement vos données
  • Analyse la tendance et la saisonnalité
  • Lance 18 modèles de prévision différents
  • Compare les modèles avec des métriques de qualité
  • Exporte les résultats en Excel

Pré-requis minimum

  • Un fichier Excel (.xlsx / .xls) ou CSV
  • Une colonne "Date" (mensuelle, trimestrielle, annuelle)
  • Au moins 12 observations pour une analyse complète

Formats de données acceptés

  • Dates en lignes / Variables en colonnes (standard)
  • Dates en colonnes / Variables en lignes (transposé)
  • Auto-détection de l'orientation au chargement

Module I — Import & Collecte des Données

Étapes d'import

  1. Cliquer sur "📥 Data" dans la barre latérale
  2. Déposer le fichier Excel ou CSV dans la zone d'upload
  3. Choisir l'orientation des données (ou laisser en auto)
  4. Ignorer des lignes / colonnes superflues si nécessaire
  5. Cliquer sur "Valider et sauvegarder"

Ce que l'outil fait automatiquement

  • Détecte l'orientation (lignes / colonnes)
  • Convertit les dates en tous formats (FR/EN, slash, tiret…)
  • Remplace les virgules décimales par des points
  • Convertit toutes les valeurs en numérique
  • Affiche un résumé : période, nb variables, nb observations

⚠ Important : La première colonne doit être la date, ou sera renommée automatiquement Date.

Modèles Statistiques & Économétriques

Adaptés aux séries économiques, financières et macroéconomiques

Modèles Univariés

  • NAIVE Moyenne mobile simple — référence de base
  • AR(p) Auto-régression sur p décalages

  • SARIMA ARIMA + composante saisonnière

Modèles Multi-variés

  • VAR Vecteur Auto-Régressif — plusieurs variables liées
  • SVAR VAR Structurel — avec contraintes économiques
  • BVAR VAR Bayésien — avec a priori informatifs
  • ARDL Retards distribués auto-régressifs
  • MIDAS Données mixtes haute/basse fréquence
  • Prophet Modèle additif Facebook — tendance + saisonnalité

Quel Modèle Choisir ? — Guide Rapide

Selon la Structure de la Série

  • Tendance + Saisonnalité
    → SARIMA Prophet LSTM
  • Tendance seule
    → ARIMA XGBoost LightGBM
  • Saisonnalité seule
    → SARIMA Exp. Smoothing Prophet
  • Série stationnaire
    → AR(p) VAR GARCH

Selon le Nombre de Variables

  • 1 variable → ARIMA, SARIMA, Prophet, LSTM, Random Forest
  • 2+ variables → VAR, SVAR, BVAR, ARDL, MIDAS
  • Volatilité financière → GARCH
💡 Bonne pratique : Lancez plusieurs modèles et comparez leurs métriques MAPE, RMSE, MAE pour choisir le meilleur.

Module IV

Évaluation & Comparaison

Mesurer et comparer la précision des modèles avec des métriques scientifiques

Comment l'Outil Évalue la Précision des Modèles ?

MAPE Mean Absolute Percentage Error
Erreur moyenne en pourcentage — facile à interpréter
RMSE Root Mean Squared Error
Pénalise fortement les grandes erreurs
MAE Mean Absolute Error
Erreur absolue moyenne — robuste aux outliers

Interprétation du MAPE

  • 🟢 Excellent   MAPE < 10% — prévision très fiable
  • 🟠 Bon        MAPE entre 10% et 20%
  • 🔴 Mauvais   MAPE > 20% — modèle peu adapté

Comparaison Multi-modèles

Après chaque prévision lancée, l'outil ajoute le modèle à un tableau de comparaison. Vous pouvez comparer visuellement les trajectoires de prévision de plusieurs modèles sur le même graphique.

Exporter les Prévisions — Options Disponibles

Export 1 — Toutes les Variables

  1. Choisir le modèle et la période de prévision

    → Variables en lignes / Dates en colonnes
  3. Cliquer sur "Générer Excel avec toutes les prévisions"
  4. Télécharger le fichier .xlsx généré

Export 2 — Variables Sélectionnées

  1. Choisir les variables à inclure dans l'export
  2. Choisir l'orientation du tableau Excel
  3. Cliquer sur "Exporter les prévisions sélectionnées"
