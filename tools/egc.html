Équilibre Général Concurrentiel (EGC)

Définition (économie d'échange $2\times2$)

Un vecteur de prix $p^* = (p_1^*, p_2^*)$ est un prix d'EGC si, à $p^*$, tous les marchés sont équilibrés : $$x_1^A(p^*) + x_1^B(p^*) = \bar X_1^A + \bar X_1^B,\qquad x_2^A(p^*) + x_2^B(p^*) = \bar X_2^A + \bar X_2^B.$$ On note allocation d'EGC $E(p^*) = (x_1^A(p^*), x_2^A(p^*), x_1^B(p^*), x_2^B(p^*))$.

Numéraire : fixer $p_2=1$ (le niveau général des prix est indéterminé, seuls les prix relatifs importent).

Demande marshallienne (formes utilisées)

Cobb‑Douglas \(U = x^{\alpha} y^{\beta}\) : \(x = \tfrac{\alpha}{\alpha+\beta}\,\tfrac{R}{p_x}\), \(y = \tfrac{\beta}{\alpha+\beta}\,\tfrac{R}{p_y}\).

Log‑linéaire \(U = \alpha\ln x + \beta\ln y\) : identique à Cobb‑Douglas (parts \(\alpha/(\alpha+\beta)\)).

CES \(U = (\alpha x^\rho + \beta y^\rho)^{1/\rho}\), \(\sigma=1/(1-\rho)\) : $$x = \frac{R}{p_x}\,\frac{\alpha^{\sigma} p_x^{1-\sigma}}{\alpha^{\sigma} p_x^{1-\sigma}+\beta^{\sigma} p_y^{1-\sigma}},\qquad y = \frac{R}{p_y}\,\frac{\beta^{\sigma} p_y^{1-\sigma}}{\alpha^{\sigma} p_x^{1-\sigma}+\beta^{\sigma} p_y^{1-\sigma}}.$$

Leontief \(U = \min\{x/a,\, y/b\}\) : \(x = \dfrac{aR}{p_x a + p_y b}\), \(y = \dfrac{bR}{p_x a + p_y b}\).

Théorème de Walras

Dans une économie concurrentielle, si \((n-1)\) marchés sont en équilibre, le dernier l'est aussi. On normalise en fixant un numéraire et l'on résout \((n-1)\) équations pour \((n-1)\) prix relatifs.

Vérification pratique : il suffit d'imposer l'équilibre du bien 1, le second suivra automatiquement.

Exercice (économie d'échange)

Considérer deux consommateurs A et B avec dotations données. Déterminer l'EGC : (i) calculer les demandes marshalliennes \(x_i^j(p,R_j)\), (ii) poser l'équilibre du bien 1, (iii) choisir un numéraire, (iv) résoudre \(p_1^*\) et l'allocation.

Exercice (avec production)

Introduire deux entreprises F et G avec fonctions de production de type Cobb‑Douglas. Écrire les conditions d'optimalité des firmes, intégrer les demandes d'inputs, et imposer l'équilibre « ressource = emploi » sur chaque marché (biens et facteurs). Discuter l'existence (rôle des rendements).
